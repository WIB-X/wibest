Usage notes

Sizing

The iframe inherits its width from your container. Default height is 500px; bump to 700px for top-30 lists. The widget is internally responsive — phones, tablets, and desktops all work.

Attribution

Each embed shows a small "Powered by WIB" footer linking to wibest.in. This is required and cannot be removed (it is what keeps the widget free). Beyond that, you can style your container freely.

Customising the data

The iframe URL accepts these params: type (restaurants / hospitals), city (any Indian city), filter (cuisine or specialty), limit (default 10, max 30), theme (light / dark / auto).

Example with all params: https://wibest.in/embed/widget/?type=restaurants&city=Bangalore&filter=biryani&limit=15&theme=auto
