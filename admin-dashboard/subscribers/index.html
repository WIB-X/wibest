Workflow:
  1. Click Download new only on Sunday morning before sending the digest.
  2. Open Zoho Campaigns → Contacts → Add Contacts → Import file → upload the CSV.
  3. Send your weekly digest to the imported list.
  4. Come back here and click Mark all as exported — next week, "Download new only" will only include subscribers added since this point.
