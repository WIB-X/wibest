Sponsored placement — component template

Internal fulfilment tool (not indexed). Copy the block, fill the four fields, paste it into the target page.
The four rules this component enforces — never remove them:
  • The amber “Sponsored” badge stays, every time.
  • The link carries rel="sponsored nofollow noopener" — never make a sponsor link dofollow (Google policy + trust).
  • It links to /how-we-make-money/ so readers can see the disclosure.
  • Place it above or below editorial content — never inside or between ranking rows.

How to use

  1. Copy the HTML below.
  2. Replace SPONSOR_NAME, SPONSOR_ONE_LINER, SPONSOR_URL, and CTA_TEXT.
  3. Paste it into the target page (e.g. inside <main> on /finance/best-mutual-fund-app/), as a sibling of the content — not inside a list.
  4. It uses the site’s theme variables, so it renders correctly in light and dark automatically.
